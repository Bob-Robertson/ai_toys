How it works: the result image is optimized by gradient descent so its deep features match the content image and its feature correlations (Gram matrices) match the style image. Because the page can’t download pretrained weights such as VGG-19, it uses a fixed randomly initialised convolutional network, which still captures color and texture statistics. Try different random networks for different looks.
